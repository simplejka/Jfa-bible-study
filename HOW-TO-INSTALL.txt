PROPHET, PRIEST & KING — INSTALL ON YOUR PHONE

This folder is a complete app. Put it on a free web address once, then add it
to your home screen. After the first open it works offline.

1) PUT IT ONLINE (one time, about 5 minutes, free)
   Option A - Netlify Drop
     - On a computer, go to https://app.netlify.com/drop and sign up (free).
     - Unzip this file and drag the whole folder onto the page.
     - Netlify gives you an address like https://your-name.netlify.app
       (you can rename it under Site configuration).
   Option B - GitHub Pages
     - Create a new public repository on github.com.
     - Upload every file in this folder (Add file > Upload files).
     - Settings > Pages > Deploy from a branch > main > / (root) > Save.
     - Your address: https://YOUR-USERNAME.github.io/REPO-NAME/

2) ADD IT TO YOUR HOME SCREEN
   iPhone (Safari): open the address > Share button > Add to Home Screen > Add.
   Android (Chrome): open the address > menu (three dots) > Install app
                     (or Add to Home screen).

3) USE IT
   - It opens straight to today's session.
   - Tap "Mark this session complete" to track your progress.
   - Progress is saved on your phone. Deleting the app clears it.
